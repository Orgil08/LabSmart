## Overleaf
1. `.tex` файл болон `assets/`-ийг project-д оруулна.
2. Compiler-ийг XeLaTeX болгоно.
3. Зохиогч, удирдагч багш, хөтөлбөрийн нэрийг шалгана.
4. Эх файлыг сургуулийн шаардлагад нийцүүлэн үргэлжлүүлэн засварлана.

## Анхаарах зүйл
Тайлан нь төслийн эх код болон удирдамжид тулгуурласан. Demo өгөгдөл нь бодит ML accuracy-ийн нотолгоо биш. README ба upgrade notes-д integration test-ийн тооны зөрүү байгаа тул эцсийн код дээр дахин тест ажиллуулах шаардлагатай.
